## Objetivo

Este projeto tem como objetivo praticar automação de testes web utilizando Playwright, aplicando boas práticas como:

- Page Object Model (POM)
- Organização por páginas
- Reutilização de código
- Testes automatizados com Pytest

## Melhorias futuras

- Captura automática de screenshots em caso de falha
- Geração de relatórios HTML
- Execução em múltiplos navegadores
- Integração com GitHub Actions (CI/CD)
- Massa de dados dinâmica
- Logs dos testes
